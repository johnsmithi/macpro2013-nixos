# Использование

## Первый вход

- На экране GDM выберите пользователя, пароль `changeme` — по умолчанию
  загрузится **GNOME**. Чтобы попробовать **niri**, перед вводом пароля
  нажмите шестерёнку в правом нижнем углу и выберите сессию — выбор
  запоминается для пользователя.
- Сразу смените пароль: терминал → `passwd`.
- Wi-Fi: в GNOME — через Настройки; в niri — `nmtui` в терминале.
  Сеть должна быть **WPA2** (WPA3 драйвер `wl` не умеет).

## Основные клавиши niri

| Клавиши | Действие |
|---|---|
| **Super+Shift+/** | шпаргалка по всем хоткеям |
| Super+Enter / Super+T | терминал (alacritty) |
| Super+D | лаунчер (fuzzel) |
| Super+Q | закрыть окно |
| Super+стрелки / H J K L | фокус по колонкам/окнам |
| Super+1…9 | рабочие столы |
| Super+O | обзор (overview) |
| Super+F | развернуть колонку |
| Super+Space | переключить раскладку en/ru |
| Print | скриншот |
| Super+Shift+V | история буфера обмена (cliphist) |
| Super+Alt+L | заблокировать экран |
| Super+Shift+E | выйти из niri (на экран GDM) |

Фоном автоматически работают: **swaybg** (обои — положите картинку в
`~/Pictures/wallpaper.jpg` или поменяйте путь в `config.kdl`), **swayidle**
(блокировка через 10 минут простоя, отключение мониторов через 15),
**cliphist** (история буфера) и **wlsunset** (тёплый экран вечером;
координаты города задаются в `config.kdl`).

## Выключение и перезагрузка

- Из терминала (sudo не нужен): `systemctl poweroff` / `systemctl reboot`.
- Короткое нажатие физической кнопки питания — корректное выключение.
- Или выйдите из niri (Super+Shift+E) и используйте меню питания GDM.

Долгое зажатие кнопки питания — жёсткое обесточивание, только для зависшей
системы.

## Настройка niri под себя (включая масштаб)

Системный конфиг лежит в `/etc/niri/config.kdl` (read-only). Для своих
настроек скопируйте его к себе — пользовательская копия имеет приоритет:

```bash
mkdir -p ~/.config/niri
cp /etc/niri/config.kdl ~/.config/niri/config.kdl
chmod u+w ~/.config/niri/config.kdl
```

niri следит за файлом и применяет изменения **сразу при сохранении**.
Проверка синтаксиса: `niri validate`. Имена мониторов: `niri msg outputs`.

Масштаб (HiDPI) задаётся на конкретный монитор:

```
output "DP-11" {
    scale 2
}
```

Дробные значения тоже работают (`scale 1.5`). X11-приложения (через
xwayland-satellite) при масштабировании могут выглядеть слегка мыльно —
это особенность Wayland. В GNOME масштаб настраивается отдельно:
Настройки → Дисплеи.

То же с waybar: системные файлы в `/etc/xdg/waybar/`, пользовательские —
в `~/.config/waybar/`.

## Обновление системы

```bash
sudo nixos-rebuild switch --flake /etc/nixos#macpro
```

Для обновления самого nixpkgs — сначала `nix flake update` в `/etc/nixos`.
Зеркала бинарного кэша и сетевые таймауты уже вшиты в конфиг
(`nix.settings.*` в `configuration.nix`).

Если после обновления отвалился Wi-Fi — см.
[решение проблем](troubleshooting.md) (драйвер `wl` и новые ядра).
